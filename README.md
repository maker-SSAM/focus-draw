# Focus & Draw (포커스 앤 드로우)

수업 중 화면 위에 판서를 하고, 마우스 커서 위치를 강조 표시해주는 가벼운 도구입니다.
(spotmouse의 커서 강조 기능 + ZoomIt의 판서 기능 중 핵심만 구현)

## 준비물

AutoHotkey v2가 필요합니다. (설치형 프로그램으로 배포할 때는 필요 없음 — 아래 "배포용 exe 만들기" 참고)

- https://www.autohotkey.com/ 에서 v2 다운로드 후 설치

## 실행

`focus-draw.ahk` 파일을 더블클릭하면 실행됩니다.
실행하면 화면 우측 하단에 작은 컨트롤 위젯이 나타납니다.

## 사용법

### 위젯으로 조작
- **강조**: 클릭하면 마우스 커서 주위에 반투명 원형 강조 표시가 켜짐/꺼짐. 켜져 있는 동안 마우스 왼쪽 버튼을 클릭하면 진한 테두리 원이 중심으로 오므라드는 클릭 효과가 함께 표시됨
- **판서**: 클릭하면 화면 위에 그림을 그릴 수 있는 모드가 켜짐/꺼짐 (켜진 상태에서 마우스 왼쪽 버튼을 누른 채 드래그하면 그려짐)
  - 아무 키 없이 드래그: 자유롭게 손으로 그리기(자유선)
  - **Shift**를 누른 채 드래그: 직선
  - **Ctrl**을 누른 채 드래그: 사각형
  - **Ctrl+Shift**를 누른 채 드래그: 원(타원)
  - (ZoomIt과 동일한 조합입니다. 드래그를 시작할 때 누르고 있던 키로 도형이 정해집니다.)
- **⚙**: 설정 창 열기 (색상 포함 세부 설정은 여기서 조정)
- **✕**: 위젯 숨기기 (프로그램은 종료되지 않고, 트레이 아이콘·메뉴로 계속 조작 가능. 설정 창의 "위젯" 탭에서 다시 켤 수 있음)
- 위젯 왼쪽의 **⋮** 부분을 드래그하면 위젯 위치를 옮길 수 있음

### 세부 설정
트레이 아이콘 우클릭 메뉴의 **"설정..."**을 누르면 설정 창이 열립니다.
- **포인터**: 강조 원 크기 / 투명도 / 색상 / 활성화 시 마우스 커서 숨기기(체크하면 강조가 켜져 있는 동안 실제 마우스 커서 대신 작은 십자선이 표시됩니다)
- **왼쪽 클릭 효과**: 클릭 시 원이 오므라드는 효과 켜기·끄기 / 테두리 굵기 / 애니메이션 빠르기
- **판서**: 선 굵기
- **일반**: 위젯 표시 여부 (꺼도 트레이 아이콘·메뉴는 항상 남아있어 계속 조작 가능)

각 항목은 슬라이더, 양옆의 `-`/`+` 버튼, 또는 오른쪽 숫자칸에 직접 입력(Enter로 적용) 중 편한 방식으로 조절할 수 있습니다. 움직이면 바로 화면에 반영되며, **저장** 버튼을 눌러야 다음 실행 때도 유지됩니다(`settings.ini` 파일에 저장). 저장하지 않고 닫으면 이번 실행 중에만 적용됩니다.

### 작업표시줄(트레이) 아이콘으로 조작
화면 우측 하단 알림 영역의 프로그램 아이콘을 우클릭하면 **설정...**, **종료** 두 항목만 있는 메뉴가 뜹니다. 강조/판서 켜기·끄기는 아래의 전용 바로가기 아이콘이나 위젯을 이용하고, 색상 등 세부 설정은 "설정..."에서 조정합니다.

추가로, 메뉴를 거치지 않고 **클릭 한 번으로 바로 켜고 끌 수 있는 전용 아이콘 2개**(강조=빨강, 판서=파랑)가 따로 생깁니다. 처음 실행하면 작업표시줄 숨김 아이콘(^) 안에 들어있으니, 꺼내서 작업표시줄에 고정하거나 "항상 표시"로 설정해두면 다음 실행부터 계속 보입니다. 이 설정은 PC별로 한 번만 해두면 유지됩니다.

(아이콘 그림은 `icon_spotlight.png`, `icon_draw.png` 파일을 사용합니다 — `focus-draw.ahk`와 같은 폴더에 있어야 합니다. exe로 컴파일하면 이 파일들이 exe 안에 함께 포함되어 별도로 들고 다닐 필요는 없습니다.)

### 단축키로 조작
- `Ctrl+Alt+H`: 마우스 강조 표시 켜기/끄기
- `Ctrl+Alt+D`: 판서 모드 켜기/끄기
- `Ctrl+Alt+C`: 판서 내용 지우기 (언제든 사용 가능)
- `Esc`: 판서 모드가 켜져 있을 때, 판서 내용을 지움 (판서 모드는 유지됨 — 종료하려면 판서 버튼/단축키를 다시 사용)

## 배포용 exe 만들기 (다른 선생님 PC에 설치 없이 배포)

1. AutoHotkey v2 설치 시 함께 설치되는 **Ahk2Exe** 실행 (또는 `focus-draw.ahk` 우클릭 → "Compile Script")
2. Source: `focus-draw.ahk` 지정, Base File은 AutoHotkey v2 64-bit 선택
3. 생성된 `focus-draw.exe` 하나만 전달하면, 받는 PC에 AutoHotkey가 설치되어 있지 않아도 바로 실행됨

## 알려진 제한사항 (필요하면 추후 개선 가능)

- 판서 모드가 켜진 동안에는 화면 전체가 판서 오버레이로 덮여, 아래 화면(웹페이지 링크, 텍스트 등)이 실수로 클릭/드래그되지 않도록 마우스 입력을 판서 오버레이가 가로챕니다. 화면 내용은 그대로 보이고, 판서 모드를 끄면 정상적으로 조작 가능합니다.
- 모니터 구성을 실행 중간에 바꾸면(연결/해제) 다시 실행해야 정상 동작합니다.
- 위젯 위치는 프로그램을 껐다 켜면 초기화됩니다. 그 외 설정(크기/투명도/색상 등)은 설정 창에서 "저장"을 눌러야 다음 실행 때도 유지됩니다.
- "활성화 시 마우스 커서 숨기기"가 켜진 상태에서 프로그램을 정상적으로 종료(트레이 메뉴의 "종료")하면 마우스 커서가 원래대로 돌아옵니다. 다만 작업 관리자 등으로 강제 종료하면 커서가 계속 안 보일 수 있는데, 이 경우 프로그램을 다시 실행하면 자동으로 복구됩니다.
