# Focus & Draw (포커스 앤 드로우)

수업 중 화면 위에 판서를 하고, 마우스 커서 위치를 강조 표시해주는 가벼운 도구입니다.
(spotmouse의 커서 강조 기능 + ZoomIt의 판서 기능 중 핵심만 구현)

## 준비물

배포용 `focus-draw.exe`를 받았다면 아무것도 설치할 필요 없이 바로 실행하면 됩니다.
소스(`focus-draw.ahk`)로 직접 실행하려면 AutoHotkey v2가 필요합니다.

- https://www.autohotkey.com/ 에서 v2 다운로드 후 설치

## 실행

`focus-draw.exe`(또는 `focus-draw.ahk`) 파일을 더블클릭하면 실행됩니다.
실행하면 화면 우측 하단에 작은 컨트롤 위젯이 나타납니다.

처음 exe를 실행하면 "Windows의 PC 보호" 파란 경고창이 뜰 수 있습니다(서명되지 않은 개인 제작 프로그램에 항상 뜨는 안내입니다). **추가 정보 → 실행**을 누르면 되고, 같은 PC에서는 한 번만 확인하면 됩니다.

## 사용법

### 위젯으로 조작
- **강조**: 클릭하면 마우스 커서 주위에 반투명 원형 강조 표시가 켜짐/꺼짐. 켜져 있는 동안 마우스 왼쪽 버튼을 클릭하면 진한 테두리 원이 중심으로 오므라드는 클릭 효과가 함께 표시됨
- **판서**: 클릭하면 화면 위에 그림을 그릴 수 있는 모드가 켜짐/꺼짐 (켜진 상태에서 마우스 왼쪽 버튼을 누른 채 드래그하면 그려짐)
  - 아무 키 없이 드래그: 자유롭게 손으로 그리기(자유선)
  - **Shift**를 누른 채 드래그: 직선
  - **Ctrl**을 누른 채 드래그: 사각형
  - **Ctrl+Shift**를 누른 채 드래그: 원(타원)
  - (ZoomIt과 동일한 조합입니다. 드래그를 시작할 때 누르고 있던 키로 도형이 정해집니다.)
- **톱니바퀴(설정)**: 설정 창 열기 (색상 포함 세부 설정은 여기서 조정)
- **✕**: 위젯 숨기기 (프로그램은 종료되지 않고, 트레이 아이콘·메뉴로 계속 조작 가능. 설정 창의 "위젯" 탭에서 다시 켤 수 있음)
- 위젯 왼쪽의 **⋮** 부분을 드래그하면 위젯 위치를 옮길 수 있음

### 세부 설정
위젯의 톱니바퀴 버튼 또는 트레이 아이콘 우클릭 메뉴의 **"설정..."**을 누르면 설정 창이 열립니다. 설정 창은 판서 모드가 켜진 상태에서도 열어서 바로 조작할 수 있습니다.
- **포인터**: 강조 원 크기 / 투명도 / 활성화 시 마우스 커서 숨기기(체크하면 강조가 켜져 있는 동안 실제 마우스 커서 대신 작은 십자선이 표시됩니다)
- **클릭효과**: 클릭 시 원이 오므라드는 애니메이션 켜기·끄기 / 테두리 굵기 / 빠르기 / 투명도
- **판서**: 선 굵기 / 투명도
- **위젯**: 위젯 표시 여부 / 작업표시줄 바로가기 아이콘 표시 여부 (둘 다 꺼도 트레이 아이콘·메뉴는 항상 남아있어 계속 조작 가능)
- **일반**: Windows 시작 시 자동 실행 / 색상(강조·클릭효과·판서에 공통으로 쓰이는 색)

창 아래쪽에는 **프로그램 종료**, **저장**, **닫기** 버튼이 있습니다.

각 항목은 슬라이더, 양옆의 `-`/`+` 버튼, 또는 오른쪽 숫자칸에 직접 입력(Enter로 적용) 중 편한 방식으로 조절할 수 있습니다. 움직이면 바로 화면에 반영되며, **저장** 버튼을 눌러야 다음 실행 때도 유지됩니다(`settings.ini` 파일에 저장). 저장하지 않고 닫으면 이번 실행 중에만 적용됩니다. "Windows 시작 시 자동 실행"만은 체크하는 즉시 반영되며 저장 버튼과 무관합니다.

### 작업표시줄(트레이) 아이콘으로 조작
화면 우측 하단 알림 영역의 프로그램 아이콘을 우클릭하면 **설정...**, **종료** 두 항목만 있는 메뉴가 뜹니다. 강조/판서 켜기·끄기는 위젯이나 단축키, 또는 아래의 전용 바로가기 아이콘을 이용하고, 색상 등 세부 설정은 "설정..."에서 조정합니다.

원하면 메뉴를 거치지 않고 **클릭 한 번으로 바로 켜고 끌 수 있는 전용 아이콘 2개**(강조/판서)를 추가로 켤 수 있습니다. 기본은 꺼져 있고, 설정 창의 "위젯" 탭에서 "작업표시줄 아이콘 활성화"를 체크하면 나타납니다. 처음 켜면 작업표시줄 숨김 아이콘(^) 안에 들어있으니, 꺼내서 작업표시줄에 고정하거나 "항상 표시"로 설정해두면 다음 실행부터 계속 보입니다. 이 설정은 PC별로 한 번만 해두면 유지됩니다. 켜져 있는 기능의 아이콘은 파란색으로 표시됩니다.

(아이콘 그림은 `icon_spotlight.png`, `icon_draw.png`, `settings.png` 파일을 사용합니다 — 소스로 실행할 때는 `focus-draw.ahk`와 같은 폴더에 있어야 합니다. exe로 컴파일하면 이 파일들이 exe 안에 함께 포함되어 별도로 들고 다닐 필요는 없습니다.)

### 단축키로 조작
- `Ctrl+Alt+H`: 마우스 강조 표시 켜기/끄기
- `Ctrl+Alt+D`: 판서 모드 켜기/끄기
- `Ctrl+Alt+C`: 판서 내용 지우기 (언제든 사용 가능)
- `Delete`: 판서 모드가 켜져 있을 때, 판서 내용만 지움 (판서 모드는 유지됨)
- `Esc`: 판서 모드가 켜져 있을 때, 판서 내용을 지우고 판서 모드도 종료

`Delete`와 `Esc`는 판서 모드가 켜져 있는 동안에만 이 프로그램이 가로채며, 그동안은 다른 프로그램에 전달되지 않습니다. 예를 들어 파워포인트 슬라이드쇼 중 판서 모드에서 `Esc`를 누르면 슬라이드쇼가 끝나는 게 아니라 판서만 종료되고, 한 번 더 누르면 슬라이드쇼가 끝납니다.

## 배포용 exe 만들기 (다른 선생님 PC에 설치 없이 배포)

AutoHotkey v2에 포함된 컴파일러 **Ahk2Exe**로 만듭니다. 설치 폴더에 `Compiler\Ahk2Exe.exe`가 없으면 `AutoHotkey\UX\install-ahk2exe.ahk`를 실행해 먼저 설치합니다. 그 다음 프로젝트 폴더에서:

```
"C:\Program Files\AutoHotkey\Compiler\Ahk2Exe.exe" /in focus-draw.ahk /out focus-draw.exe /base "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe"
```

생성된 `focus-draw.exe` 하나만 전달하면, 받는 PC에 AutoHotkey가 설치되어 있지 않아도 바로 실행됩니다. 압축(UPX 등) 옵션은 백신 오탐이 늘어나므로 쓰지 않습니다.

프로그램 아이콘과 이름은 `focus-draw.ahk` 맨 위의 `;@Ahk2Exe-...` 주석 줄이 정합니다. 이 줄들은 컴파일할 때만 읽히므로 `.ahk`로 그냥 실행할 때는 아무 영향이 없습니다. 아이콘을 바꾸려면 `icon.png`를 교체한 뒤 여러 크기(16~256px)를 담은 `focus-draw.ico`로 다시 변환해 덮어쓰고 컴파일하면 됩니다.

## 알려진 제한사항 (필요하면 추후 개선 가능)

- 판서 모드가 켜진 동안에는 화면 전체가 판서 오버레이로 덮여, 아래 화면(웹페이지 링크, 텍스트 등)이 실수로 클릭/드래그되지 않도록 마우스 입력을 판서 오버레이가 가로챕니다. 화면 내용은 그대로 보이고, 판서 모드를 끄면 정상적으로 조작 가능합니다. (위젯과 설정 창은 판서 중에도 조작할 수 있습니다.)
- 판서 모드 중에도 마우스 강조 하이라이트는 화면에서 잠시 사라집니다(강조가 꺼지는 것은 아니고, 판서를 끄면 다시 보입니다).
- 판서 모드 중 `Win+Shift+S`로 화면을 캡처하면, 캡처 도구 위에서의 드래그는 판서로 그려지지 않습니다.
- 모니터 구성을 실행 중간에 바꾸면(연결/해제) 다시 실행해야 정상 동작합니다.
- 위젯 위치는 프로그램을 껐다 켜면 초기화됩니다. 그 외 설정(크기/투명도/색상 등)은 설정 창에서 "저장"을 눌러야 다음 실행 때도 유지됩니다.
- "활성화 시 마우스 커서 숨기기"가 켜진 상태에서 프로그램을 정상적으로 종료(트레이 메뉴의 "종료")하면 마우스 커서가 원래대로 돌아옵니다. 다만 작업 관리자 등으로 강제 종료하면 커서가 계속 안 보일 수 있는데, 이 경우 프로그램을 다시 실행하면 자동으로 복구됩니다.
