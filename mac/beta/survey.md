# 맥용 Focus & Draw 시험판 0.5.0 — 설문지 문항 (결정 8: 설문지)

> 파일로 주고받을 때는 같은 문항을 담은 [답장지.txt](답장지.txt)를 보낸다(UTF-8, 메모장·텍스트 편집기로 열림). 답은 파일째 돌려받거나 내용을 메신저에 붙여 넣게 한다.

선생님이 구글 설문지 등에 아래대로 옮겨 만든다. 링크는 zip과 [quick-guide.md](quick-guide.md)를 받는 분께 함께 보낸다.
앞 머리글: "받아 쓰신 뒤 약 5분 확인과 아래 질문에 답해 주세요. 이름·학교는 묻지 않습니다. 막힌 곳이 있으면 메뉴 막대 아이콘 › 도움말 › 진단 정보 복사를 붙여 넣어 주세요."

## A. 기본 (알파 질문지와 같다)
1. 맥 모델과 macOS 버전 (짧은 답)
2. 관리자 계정인가요? 설치할 때 암호를 넣을 수 있었나요? (예 / 아니요 / 모름)
3. 학교가 관리하는 맥인가요? (예 / 아니요 / 모름)
4. 쓰는 발표 앱 (여러 개 선택: 키노트 / 파워포인트 / 구글 슬라이드 / 크롬·웹 / 기타)
5. 프로젝터·TV·전자칠판을 쓰나요? 어떻게 연결하나요? (문단)

## B. 5분 확인 (각각 잘 됨 / 안 됨 / 해 보지 않음 + 한 줄)
1. **설치**: 읽어주세요 1번을 따라 처음 열기까지 됐나요? 어디서 막혔나요? 얼마나 걸렸나요?
2. **자기 발표 앱에서 F9**: 발표(쇼) 중에 fn+F9 또는 ⌃⌥2로 드로잉이 켜지고 그려지나요? 끄면 슬라이드가 다시 넘어가나요?
3. **위젯**: 화면 오른쪽 아래에 보이고, 눌러서 강조·드로잉이 켜지나요?
4. **프로젝터**: 연결한 채로 그려도 맥북 화면의 그림이 제자리에 있나요? 뺐다 꽂아도 그대로인가요?
5. **실행 취소**: ⌘Z로 되돌려지나요? Esc로 끄고 다시 켠 뒤 1분 안에 ⌘Z로 돌아오나요?

## C. 의견
1. 처음 헷갈린 순간은 어디였나요? (문단)
2. 망가지거나 이상했던 것이 있나요? 언제, 어떤 순서로? (문단)
3. 수업 중에 쓸 수 있겠다고 느꼈나요? (예 / 아직 / 아니요) 이유는?
4. Windows 판과 다르게 느낀 점, 있었으면 하는 기능 (문단)
5. 진단 정보 (선택, 붙여 넣기)
6. 2주 뒤에도 답을 받아도 되나요? (예 / 아니요)
