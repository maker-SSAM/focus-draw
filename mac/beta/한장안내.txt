Focus & Draw 맥용 — 한 장 안내 (시험판 0.5.0)
=============================================

수업 중 화면의 한 곳을 강조하고(F8), 화면 위에 바로 필기합니다(F9).
"손쉬운 사용", "화면 기록", "입력 모니터링" 권한을 요구하지 않습니다.


■ 켜고 끄기
------------------------------------------
              키              맥북에서 (F키가 음악·밝기 키일 때)
  강조        F8              fn + F8   (또는 control + option + 1)
  드로잉      F9              fn + F9   (또는 control + option + 2)

화면 오른쪽 아래의 작은 위젯을 눌러도 켜고 끌 수 있습니다.
키노트·파워포인트 쇼 중에는 메뉴 막대가 없으니, 메뉴는 위젯을 오른쪽 클릭(또는 control+클릭)으로 여세요.
강조 중에는 마우스 화살표 대신 원 한가운데에 작은 십자가 보입니다.


■ 드로잉 중에 쓰는 키
------------------------------------------
  끌기                      자유선
  오른쪽 끌기 / option+끌기   지우개 (트랙패드는 option+끌기)
  1 ~ 9                     펜 색
  0                         기본 색
  A                         사라지는 펜 (레이저)
  S                         무지개 펜
  Q / W / E / R             칠판: 없음 / 흰색 / 녹색 / 검정
  Z + 끌기                  직선
  X + 끌기                  물결
  C + 끌기                  화살표
  shift + 끌기              사각형
  control + 끌기            원
  + / -                     굵기 (option을 누르고 +/-: 지우개 크기)
  마우스 휠                 진하게 / 연하게
  command + Z               실행 취소
  delete                    전부 지우기
  Esc                       그린 것을 지우고 끄기
  F9 (fn+F9)                그린 것을 남기고 끄기


■ 알아 두세요
------------------------------------------
- 드로잉 중에는 화살표·스페이스·발표 리모컨 키가 막힙니다.
  슬라이드를 넘기려면 F9나 Esc로 드로잉을 먼저 끄세요.
- 다른 앱으로 넘어가거나, 잠자기·화면 잠금이 되거나, 프로젝터 선을 뽑으면 드로잉이 저절로 꺼지고 그린 것이 지워집니다.
  다시 켜고 command+Z를 누르면 1분 안에는 돌아옵니다.
- 처음 열 때 "열 수 없습니다"가 뜨면, 함께 받은 "맥용 읽어주세요.txt"의 0번(응용 프로그램 폴더로 옮기기)과 1번(여는 방법)을 따라 하세요.
  새 판을 받을 때마다 한 번 해야 합니다.


■ 이상하면
------------------------------------------
메뉴 막대 아이콘 > 도움말 > "진단 정보 복사"를 누른 뒤, 붙여 넣어(command+V) 무슨 일이 있었는지와 함께 보내 주세요.
이름, 컴퓨터 이름, 입력한 글자는 들어 있지 않습니다.
