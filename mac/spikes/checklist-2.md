# 집에서 하는 재시험 (S1c-1 → S1c-2)

> 맥북에서 약 25분. 첫 집 시험(checklist.md)은 실험 항목을 고르지 않은 채 **모두 B안(지금 방식)**으로 돌았습니다.
> 그 결과는 B안 자료로 잘 쓰고, 이번에는 **C안**을 중심으로 다시 봅니다. `(선택)` 항목은 건너뛰어도 됩니다.
> 답은 전처럼 짧게: `1 a X: 쇼가 꺼짐`. 모르는 건 `?`, 못 한 건 `-`.

## 준비 (3분) — 꼭 순서대로

1. **어젯밤 켜 둔 Focus & Draw를 종료**합니다. (메뉴 막대 아이콘 또는 위젯 오른쪽 클릭 › Focus & Draw 종료)
2. Finder에서 `focus-draw/mac/build/Focus & Draw.app`을 엽니다. (오늘 새로 만든 판입니다)
3. 메뉴를 열어 **"진단 기록"에 체크**가 있는지 봅니다. 없으면 눌러서 켭니다.
4. 사파리를 **전체 화면**(창 왼쪽 위 초록 단추)으로 만들어 둡니다. 키노트 문서(3장 이상)와 메모 앱도 열어 둡니다.
5. ⭐ **메뉴 › 실험 › 재시험 항목 고르기 › R1**을 누릅니다.
6. 확인: ⌃⌥2를 누르면 커서 옆에 **"R1 · C안"**이 2초 뜹니다. → Esc로 끕니다.
   - **"항목 없음 · B안"이 뜨면** 5번을 다시 합니다. 이 표시가 맞아야 시험이 의미가 있습니다.

메뉴 여는 법: 메뉴 막대 아이콘, 또는 **위젯 오른쪽 클릭**(트랙패드 두 손가락 탭). 키노트 쇼 중에는 메뉴 막대가 숨으므로 위젯으로 엽니다.

## R1 · C안 — 1번부터 11번까지 (약 18분)

C안은 드로잉 키만 가로채고 나머지 키(→, 리모컨)는 발표 앱으로 보내는 방식입니다(Windows 판과 같음).
드로잉을 켤 때마다 커서 옆에 **"R1 · C안"**이 뜨는지 곁눈으로 봐 주세요.

### 1. 키노트 쇼 ⭐ (3분)

키노트에서 **재생**(전체 화면) → ⌃⌥2

- a. 쇼가 **그대로 있다** (첫 시험처럼 꺼지지 않는다)
- b. 마우스를 움직이면 **빨간 점**이 따라다닌다
- c. 끌면 선이 그려진다
- d. **→ 키**(리모컨이 있으면 리모컨도)로 슬라이드가 **넘어간다**. 그린 선은 남아 있다
- e. Esc 한 번 → 드로잉이 꺼지고 선이 사라진다. 쇼는 그대로다
- f. 쇼 위에 위젯이 보인다 → 위젯 오른쪽 클릭 → 메뉴가 뜬다 → 메뉴 바깥을 한 번 클릭해 닫는다. 쇼는 그대로다
- g. Esc → 쇼가 끝난다

예상: a~g 모두 O. **a나 c가 X이면** 13번(R3·R4)도 해 주세요.

결과: 모두 잘 되고 있어. 실험과 상관없는 의견인지 모르겠으나, 나는 드로잉모드에서는 캡쳐나 중요한 단축키를 제외한 키는 막혀도 좋다고 생각해.(어떤 방법이 더 좋을지는 좀더 같이 생각 해 보자.) 키노트 전체화면에서는 커서가 여전히 보이지 않고 있어.(이건 네가 키노트 자체 기능이라고 말했던 것 같아.)

### 2. 드로잉 키 (4분)

키노트 재생 → ⌃⌥2 → 차례로:

- a. 3 → 노랑 / W → 흰 칠판 / Q → 칠판 치움 / 1 → 빨강
- b. **Z를 누른 채** 끌기 → 직선. Z를 떼고 끌기 → 다시 자유선
- c. **⇧를 먼저 누르고** Z까지 누른 채 끌기 → 가로·세로·45°로 맞춘 직선
- d. X 누른 채 → 물결, C 누른 채 → 화살표
- e. **+를 길게** 누르기 → 숫자가 계속 커진다 (한 번만 커지면 X)
- f. A → 사라지는 펜, S → 무지개 펜
- g. delete → 전부 지워짐 → ⌘Z → 되돌아옴
- h. 트랙패드 두 손가락으로 위아래 → % 숫자가 뜨며 진하기가 바뀜

예상: 모두 O

결과: 모두O

### 3. 한글 입력 상태 (2분)

메뉴 막대 입력기를 **한글**로 바꾼 뒤 키노트 재생 → ⌃⌥2 → 3, Z 직선, + 길게, delete, Esc 두 번.

예상: 영문일 때와 똑같다.

결과: 영문일 때와 똑같아.

### 4. 끈 뒤에 글자가 쳐지는가 ⭐ (3분)

**가장 중요합니다.** C안은 드로잉 중에 글자 키를 잡아 두므로, 끈 뒤에 꼭 풀려야 합니다.

1. 메모 앱에 새 메모 → ⌃⌥2 → 한 획 → **Esc**로 끄기 → 메모에 `qwer as zxc 1234567890 +-=` 치고 지우기
2. ⌃⌥2 켜기 → **⌃⌥2**로 끄기 → 같은 글자 치기
3. ⌃⌥2 켜기 → **위젯 드로잉 버튼**으로 끄기 → 같은 글자 치기

예상: 세 번 모두 모든 글자가 쳐진다.
**하나라도 안 쳐지면** 결과에 적고 바로 위젯 오른쪽 클릭 › 종료 (종료하면 풀립니다).

결과: 모두 잘 작동해.

### 5. 사파리 전체 화면 — 오늘 고친 것 (2분)

준비 4번에서 전체 화면으로 둔 사파리로 갑니다 (창을 줄였다 키우지 마세요).

- a. ⌃⌥2 → **처음부터 바로** 빨간 점이 보이고 그려진다 → Esc
- b. ⌃⌥1(강조) → 원이 보인다 → ⌃⌥1로 끄기

예상: a O, b O (첫 시험에서는 창을 줄였다 키워야 됐음)

결과: 잘 작동함.

### 6. 암호 칸 (선택, 2분)

사파리에서 로그인 페이지의 **암호 칸을 클릭**만 한 채 → ⌃⌥2 → 그려지나? 3·Z·delete가 되나? → Esc → 암호 칸에 글자가 쳐지나?

예상: 그려짐 O, 키는 X일 수 있음(암호 칸이 키를 막음), 끈 뒤 암호 칸 입력 O

결과: 드로잉모드 작동함. 단축키도 잘 작동함. 끄고난 뒤 암호칸에도 입력됨. 실험에 없는게 하나 있는데, 암호칸에 둔 상태로 단축키가 아닌 다른 키들을 누르면 입력 됨.

### 7. 파워포인트 쇼 (선택, 2분)

슬라이드 쇼 시작 → ⌃⌥2 → 보이나, 그려지나, → 로 넘어가나, Esc 두 번.

예상: 모두 O (첫 시험 B안에서는 → 가 안 넘어갔음)

결과: 모두 작동함. 하지만 1번에서도 이야기 했듯이, 프레젠테이션을 넘기는 버튼은 오히려 강의에 방해가 될 것 같기도 해.(논의해보자)

### 8. 드로잉 중 ⌘Tab (1분)

키노트 재생 → ⌃⌥2 → 선 하나 → ⌘Tab으로 메모 → 메모에 `abc 123`을 쳐 본다 → ⌘Tab으로 키노트 → Esc 두 번.

- a. 메모로 넘어갔을 때 판(선)은 어떻게 되나?
- b. 메모에 글자가 쳐지나, 아니면 드로잉 키로 먹히나?

예상: 결과 그대로 적어 주세요 (C안은 드로잉이 켜져 있는 동안 글자 키를 잡아 둡니다)

결과: 키노트 재생중에는 ⌘Tab 버튼이 작동하지 않는다. 다른 앱에서 드로잉모드를 켠 후에 ㅔ모앱으로 넘어갔을때에는 메모에 드로잉키로 먹힘.(위에서 언급 했듯 드로잉 모드는 한 화면에서만 머무르고 굳이 ⌘Tab버튼을 활용하지는 않을 것 같아. 오히려 막는게 더 깔끔할것 같기도 하고.)

### 9. 붓 커서 (3분)

바탕화면에서 ⌃⌥2 →

- a. 켜자마자(마우스를 움직이기 전에도) 빨간 점이 보인다
- b. ⌥ 누른 채 = 를 9번 → ⌥ 누른 채 끌기 → 커다란 지우개 링이 **잘리지 않고** 보인다
- c. 시스템 설정 › 손쉬운 사용 › 디스플레이 › **포인터 크기**를 최대로 → 빨간 점 크기가 **그대로**다 (보고 나서 원래대로)
- d. 빨간 점이 마우스를 늦게 따라오거나 끊겨 보이지 않는다

예상: a O, b O, c O(그대로), d O

결과: 모두 잘 작동해. 하지만 [⌥ 누른 채 = 를 9번] 누르면, 빨간 점인 상태로 숫자만 바뀌어(지우개의 크기변화가 바로 보이지 않아. ⌥ 누른상태+마우스 클릭이 동시에 작동해야 지우개가 활성화 되는것 같아. 이 부분을 어떻게 해결할지 고민 해 봐야겠어.

### 10. 잠자기 (2분)

⌃⌥2 → 선 몇 개 → **덮개 닫고 15초** → 열고 잠금 풀기 →

- a. 선이 남아 있고, **첫 클릭부터** 그려진다
- b. Esc로 꺼진다 → 메모에 글자가 쳐진다

예상: a O, b O (첫 시험 B안에서는 첫 클릭이 메모로 갔음)

결과: 모두 잘 돼. 그런제 문제는 이 앱(프로그램)의 목적은 '간단하고 휘발성있는' 드로잉이야. 강의 중간에 잠시 켜서 드로잉하고 간편하게 끄는거지. 잠자기모드가 시작되면 esc효과를 주는게 좋겠어. 그리고 esc후에도 드로잉 이력을 오랫동안 기억하면서 컴퓨터의 성능을 갉아먹지 않으면 좋겠어. 윈도우 버전에서 이에관한 해결책이 있었어. 참고해줘.

### 11. 확대/축소 (선택, 1분)

손쉬운 사용 › 확대/축소 › "키보드 단축키"가 켜져 있으면: ⌥⌘8 → ⌥⌘=로 확대 → ⌃⌥2 → 선이 커서 자리에 그려지나? → Esc → ⌥⌘8로 끄기. 꺼져 있으면 `-`.

결과: 잘 작동 해.

## R2 · A안 — 12번 (2분)

**메뉴 › 실험 › 재시험 항목 고르기 › R2** → ⌃⌥2를 눌러 **"R2 · A안"**이 뜨는지 확인 → Esc.

### 12. A안 · 키노트 쇼

키노트 재생 → ⌃⌥2 → a. 쇼가 그대로인가 b. 그려지나 c. → 로 넘어가나 d. 3·Z가 되나 e. Esc 두 번

예상: a O, b O, c X(A안은 판이 키를 받음), d O, e O

결과: a O, b O, c X(A안은 판이 키를 받음), d O, e O 예상대로야.

## R5 · 강조 중 커서 숨기기 — 14번 (3분)

**메뉴 › 실험 › 재시험 항목 고르기 › R5** (이번에는 드로잉을 켜지 않아도 됩니다)

### 14. 강조 중 화살표 숨기기

⌃⌥1로 강조 켜기 →

- a. 바탕화면(Finder)·사파리에서 화살표가 사라지고 빨간 원만 보인다
- b. 키노트 쇼 위에서도 원만 보인다
- c. Dock 위로 가면? (macOS가 막아서 화살표가 보일 수 있음)
- d. ⌃⌥1로 끄면 화살표가 돌아온다
- e. 다시 켠 채로 위젯 오른쪽 클릭 › 종료 → 화살표가 돌아온다 (다시 앱 열기)

예상: a O, b O, c 보일 수 있음, d O, e O

결과: a O, b O, c화살표가 나타난다. 이후 다른곳으로 가도 계속 화살표 보임, d O, e O , 특이점 하나는 네손가락으로 화면을 쓸어 데스크탑화면을 바꾸면, 커서가 나타난다는 점. 해당 데스크탑 화면에서 포커스모드를 재작동하면 커서가 사라짐,드로잉모드의 빨간 점 역시, 독을 열고 닫거나 다른 데스크탑으로 이동하면 커서가 나타나거나, 경우에 따라 잠시 나타났다가 사라지기도 함.
