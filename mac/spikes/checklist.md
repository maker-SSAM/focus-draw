# 집에서 하는 확인 (S1b → S1c)

> **S1c-1 메모 (2026-09-29)**: 이 시험은 실험 항목을 고르지 않은 채 진행되어 **모두 B안(지금 방식)으로 돌았다**(진단 기록의 `DRAW on … key=B`). 아래 "C안" 제목의 결과도 B안 결과로 읽는다. 해석은 [../design/SPIKES.md](../design/SPIKES.md), C안 재시험은 [checklist-2.md](checklist-2.md).

> 맥북에서 약 45분(외부 모니터가 있으면 +5분). 15번까지 순서대로 하고 **"결과:"** 줄만 채워 주세요.
> 답은 `2 c X: + 길게 눌러도 한 번만 커짐`처럼 짧게 써도 됩니다. 모르는 건 `?`, 못 한 건 `-`.
> 진단 기록이 뒤에서 자동으로 남으니, 이상한 점을 설명하느라 애쓰지 않아도 됩니다.

## 준비 (5분)

1. 지금 떠 있는 Focus & Draw를 **종료**합니다 (예전 판이 떠 있어요).
2. Finder에서 `focus-draw/mac/build/Focus & Draw.app`을 엽니다.
3. **메뉴 여는 법**: 메뉴 막대 아이콘, 또는 **위젯을 오른쪽 클릭**(트랙패드 두 손가락 탭). 아이콘이 노치 뒤로 숨어 있어도 위젯으로 열립니다.
4. 메뉴에서 **"진단 기록"**을 눌러 체크 표시가 되게 합니다. 끝날 때까지 켜 둡니다.
5. 준비물: 키노트 문서(슬라이드 3장 이상), 메모 앱, 사파리, PDF 하나. 파워포인트·발표 리모컨·외부 모니터는 있으면.
6. **항목마다 먼저**: 메뉴 › 실험 › 확인 항목 고르기 › 그 번호. (슬라이드 쇼를 시작하기 **전에** 고릅니다)

단축키: 드로잉 켜기·끄기 **⌃⌥2**, 강조 켜기·끄기 **⌃⌥1** (fn 없이 됩니다).

## 0. S1a 확인 (5분, 이미 했으면 건너뛰기)

항목은 고르지 않아도 됩니다(메뉴 › 실험 › 실험 끝 상태).

1. S → 긋는 도중 3 → 앱이 꺼지지 않고, 그 획은 끝까지 무지개.
2. A → 긋는 도중 S → 빛이 1초 안에 사라진다.
3. 위젯 ✕로 숨김 → ⌃⌥2 두 번 → 위젯이 계속 숨어 있다. (메뉴 › 위젯 표시로 되돌리기)
4. 드로잉 중 트랙패드 두 손가락 탭 → 아무것도 안 지워진다. ⌘Z → 마지막 획이 취소된다.
5. 드로잉을 끈 채 메모에서 ⌘Z → 메모 자체의 실행 취소가 된다.
6. 메뉴 › 종료 → 커서가 정상이고 판이 남지 않는다. (다시 앱 열기)

결과: 모두 확인

## 1. C안 · 키노트 전체 화면 (5분) — 항목 1

C안은 드로잉 키만 가로채고 나머지 키(→, 리모컨)는 키노트로 보내는 방식입니다(Windows 판과 같음).

1. 키노트에서 **재생**(전체 화면) → ⌃⌥2
2. 확인
   - a. 마우스를 움직이면 화살표 대신 **빨간 점**이 따라다닌다.
   - b. 끌면 선이 그려진다.
   - c. **→ 키**(리모컨이 있으면 리모컨도)로 슬라이드가 **넘어간다**. 그린 선은 남아 있다.
   - d. Esc 한 번 → 드로잉이 꺼지고 선이 사라진다. Esc 한 번 더 → 쇼가 끝난다.
3. a·b가 안 되면: 키노트 › 재생 › **윈도우에서 재생**으로 한 번 더 해 보고 결과에 적어 주세요.

예상: a~d 모두 O

결과: 키노트에서 재생 후 드로잉모드를 켜면, 키노트 재생(전체화면)이 꺼짐. 그리고 키노트 재생 상태에서 마우스 커서가 사라짐(포커스 모드의 하이라이트만 남음. 클릭은 가능)

## 2. C안 · 드로잉 키 (5분) — 항목 2

키노트 재생 → ⌃⌥2 → 차례로:

- a. 3 → 노랑 선 / W → 흰 칠판 / Q → 칠판 치움 / 1 → 빨강
- b. **Z를 누른 채** 끌기 → 직선. Z를 떼고 끌기 → 다시 자유선.
- c. **⇧를 먼저 누르고** Z까지 누른 채 끌기 → 가로·세로·45°로 맞춘 직선
- d. X 누른 채 → 물결, C 누른 채 → 화살표
- e. **+를 길게** 누르기 → 숫자가 계속 커진다 (한 번만 커지면 X)
- f. A → 사라지는 펜, S → 무지개 펜
- g. delete → 전부 지워짐 → ⌘Z → 되돌아옴
- h. 트랙패드 두 손가락으로 위아래 → % 숫자가 뜨며 진하기가 바뀜
- i. 드로잉 중에 → 키 → 슬라이드 넘어감 (1번 c와 같음)

예상: 모두 O

결과: 키노트 재생 후 드로잉모드를 켜면 재생화면이 꺼짐. 모두 실험불가.

## 3. C안 · 한글 입력 상태 (2분) — 항목 3

메뉴 막대 입력기를 **한글**로 바꾼 뒤 키노트 재생 → ⌃⌥2 → 3, Z 직선, + 길게, delete, Esc.

예상: 영문일 때와 똑같다.

결과: 키노트 재생 후 드로잉모드를 켜면 재생화면이 꺼짐. 모두 실험불가.

## 4. C안 · 끈 뒤에 글자가 쳐지는가 ⭐ (3분) — 항목 4

**가장 중요합니다.** C안은 드로잉 중에 글자 키를 잡아 두므로, 끈 뒤에 꼭 풀려야 합니다.

1. 메모 앱에 새 메모 → ⌃⌥2 → 한 획 → **Esc**로 끄기 → 메모에 `qwer as zxc 1234567890 +-=` 치고 delete로 지우기
2. ⌃⌥2 켜기 → **⌃⌥2**로 끄기 → 같은 글자 치기
3. ⌃⌥2 켜기 → **위젯 드로잉 버튼**으로 끄기 → 같은 글자 치기

예상: 세 번 모두 모든 글자가 정상으로 쳐진다.
**하나라도 안 쳐지면** 결과에 적고 바로 메뉴 › 종료 (종료하면 풀립니다).

결과: 세 번 모두 글자가 정상적으로 쳐진다.

## 5. C안 · 암호 칸 (3분) — 항목 5

1. 사파리에서 아무 로그인 페이지의 **암호 칸을 클릭**만 합니다 (아무것도 입력하지 않기).
2. ⌃⌥2 → 켜지나? 그려지나? 3·Z·delete가 되나?
3. Esc → 암호 칸에 아무 글자나 쳐 보고 지우기 → 쳐지나?

예상: 켜지고 그려진다. 키는 안 될 수도 있다(기록으로 확인). 끈 뒤 암호 칸 입력은 된다.

결과: 암호칸 클릭후 드로잉모드 진입은 가능하나, 드로잉을 실시하려고 하면 아무 반응이 없음.(클릭됨) // 최초 실행시 앞과 같았으나, 다시 한 번 해보니 제대로 작동함. 해당 창의 최대화를 풀고 다시 시도했을때 가능했음. 이후 최대화 한 후에도 다시 가능.

## 11. 붓 커서 (4분) — 항목 11-1, 11-2

- a. **11-1**(B안) → 바탕화면에서 ⌃⌥2 → 커서가 빨간 점인가?
- b. 그대로 **⌥ 누른 채 = 를 9번** 눌러 지우개를 가장 크게 → ⌥ 누른 채 끌기 → 커다란 지우개 링이 **잘리거나 작게 줄어** 보이는가?
- c. 시스템 설정 › 손쉬운 사용 › 디스플레이 › **포인터 크기**를 최대로 → 빨간 점이 같이 커지는가? (보고 나서 원래대로)
- d. **11-2**(C안, 시스템 커서) → ⌃⌥2 → 커서가 빨간 점으로 바뀌는가, 화살표 그대로인가?
- e. 1번(C안, 판에 그린 커서)과 비교: 판 커서가 늦게 따라오거나 끊겨 보였나?

예상: a O, b 잘릴 수 있음, c 커질 수 있음, d 화살표 그대로일 수 있음, e 비슷함

결과: 드로잉모드 단축키를 켜면, 처음에는 화살표(커서) 모양이다가 움직이면 드로잉(빨간점) 모드로 변경됨. 앞서 말한 오류와도 비슷한것 같은데, 하이라이트 기능이 가상데스크탑을 벗어나면 작동하지 않음. 창의 최대화를 풀면 다시 작동하는데, 앞선 드로잉 모드가 막혔던것과 비슷함. 그리고 빨간점이 마우스 커서의 크기를 따라가는것 같음. 지우개의 크기 역시 마찬가지

## 12. 강조 중 커서 숨기기 (3분) — 항목 12

- a. 바탕화면(Finder), 사파리, 키노트 쇼 위에서 화살표가 사라지고 빨간 원만 보이는가?
- b. Dock 위로 가면? (macOS가 막아서 보일 것으로 예상)
- c. 키노트 쇼에서 마우스를 맨 위로 올려 메뉴 막대가 나왔다 들어간 뒤에도 계속 숨어 있나?
