# Focus & Draw — 맥용 시험판 (mac 0.2.0)

Windows 판(`focus-draw.ahk`)의 핵심 기능을 맥에서 쓸 수 있게 Swift로 다시 만든 **1단계 시험판**입니다.
macOS 15 Sequoia 이상(15에서 확인), 애플 실리콘(M1~)과 인텔 맥 모두에서 돌아갑니다. macOS 13·14는 확인한 적이 없어 지원한다고 말하지 않습니다.

## 들어 있는 것

- **위젯**: ⋮(옮기기) · 강조 · 드로잉 · 설정 · ✕(숨기기). 옮긴 자리는 바로 기억합니다
- **커서 강조**와 **클릭 효과**(좌·우 따로)
- **드로잉**: 자유선, 사각형(Shift), 원(Control), 직선·물결·화살표(Z·X·C), 방향 맞춤(Shift), 사라지는 펜(A), 무지개 펜(S), 색 1~9·0, 칠판 Q·W·E·R, 굵기 +/−, 휠로 진하기, 지우개, 실행 취소, 전부 지우기, Esc
- **메뉴 막대 아이콘**: 강조 · 드로잉 · 위젯 표시 · 설정 · 종료
- **설정 창**: 포커스 · 드로잉 · 위젯 값 (저장하면 다음 실행에도 남습니다)

## Windows 판과 다른 점

| 항목 | 맥에서는 |
|---|---|
| 단축키 | `F8`·`F9`에 더해 **`⌃⌥1`(강조)·`⌃⌥2`(드로잉)**. 맥북 키보드에서 F8·F9는 **fn과 함께** 누릅니다 |
| 지우개 | 오른쪽 버튼 드래그 **또는 `⌥ Option` + 드래그** (트랙패드에서 편함). 지우개 크기는 `⌥` + `+`/`−` |
| 실행 취소 | `⌘Z` (Ctrl+Z도 됩니다) |
| 전부 지우기 | `delete` 키 |
| 휠로 진하기 | 트랙패드 두 손가락 스크롤도 됩니다 |
| 설정 파일 | `~/Library/Application Support/Focus & Draw/settings.ini` (앱 옆이 아님) |
| 트레이 아이콘 | 화면 위쪽 **메뉴 막대** 아이콘 |

## 아직 없는 것 (2단계에서)

강조 중 커서 숨기기, 숫자키·칠판 색을 설정 창에서 바꾸기, 단축키 바꾸기, 드로잉 단축키 그림, 로그인 시 자동 실행, Dock 윗선 자석, 전자칠판 터치 제스처

## 알려진 문제

- **노치 있는 맥북에서 메뉴 막대 아이콘이 안 보일 수 있음**: 메뉴 막대가 다른 앱 아이콘으로 꽉 차면 macOS가 나중에 추가된 아이콘부터 노치 뒤로 숨깁니다. 앱 버그가 아니라 macOS 동작입니다.
  - `⌘`(커맨드) 키를 누른 채 다른 메뉴 막대 아이콘을 좌우로 옮겨 자리를 만들면 다시 나타납니다.
  - 옮길 아이콘조차 안 보이면 다른 메뉴 막대 앱을 하나 끄고 다시 시도합니다.
  - **시스템 설정 → 디스플레이 → 해상도**를 "더 많은 공간" 쪽으로 바꾸면 메뉴 막대가 넓어져 덜 가려집니다.

## 만들기

Xcode 없이 명령줄 도구만 있으면 됩니다 (`xcode-select --install`).

```bash
mac/build.sh
```

`mac/build/Focus & Draw.app`과 `mac/build/Focus-Draw-0.2.0-test-mac.zip`이 생깁니다. 이 개발용 빌드에는 시험용 "실험" 메뉴가 들어 있습니다.

- `mac/build.sh --quick`: 이 맥의 칩용으로만 빨리 (고치는 동안)
- `mac/build.sh --test`: 빨리 만든 뒤 그림 기준 점검(`Tests/golden/`)과 자체 점검을 돌려 결과를 한 줄로. 그림이 달라지면 `build/test-out/`에 차이 그림과 축소 모음이 남습니다
- `mac/build.sh --run`: 빨리 만든 뒤 켜져 있던 앱을 끄고 새 앱을 띄움
- `mac/build.sh --update-goldens`: 기준 그림을 새로 저장 (그림이 일부러 바뀌었을 때, 선생님이 새 그림을 확인한 뒤에만)
- `mac/build.sh --release`: 배포용 (실험 메뉴 없음, zip과 SHA-256)

문제가 생기면 메뉴 막대(또는 위젯 오른쪽 클릭) › **진단 기록**을 켜 두세요. `~/Library/Logs/Focus & Draw/diag.log`에 창·키·화면 상태가 남습니다(입력한 글자는 남지 않음).

Windows 판과 무엇이 같고 다른지는 **[PARITY.md](PARITY.md)** (기능 144개 차이표)에 있습니다.

## 다른 맥에 나눠줄 때

Apple 개발자 인증서로 서명하지 않은 앱이라 처음 한 번은 맥이 막습니다.

1. zip을 풀고 `Focus & Draw.app`을 **응용 프로그램** 폴더로 옮깁니다
2. 더블클릭 → "열 수 없습니다" 안내가 뜨면 **완료**
3. **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **"그래도 열기"** → 암호 입력
4. 다음부터는 그냥 열립니다

실행하면 Dock이 아니라 화면 위 **메뉴 막대**에 아이콘이 생기고, 오른쪽 아래에 위젯이 나타납니다.
