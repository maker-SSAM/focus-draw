# Windows ↔ 맥 차이표 (PARITY)

> Windows v1.0.0의 기능 144개를 맥에서 어떻게 하고 있는지 한 줄씩 적은 표. 맥 세션이 단계를 끝낼 때마다 해당 줄을 고친다.
> 원자료: [design/review-2026-09-28/windows-inventory.md](design/review-2026-09-28/windows-inventory.md) (영어, 줄마다 자세한 Windows·맥 설명)
> 결정 번호는 [ROADMAP.md](ROADMAP.md), D번호는 [design/SPIKES.md](design/SPIKES.md).

**맥 상태**: `완료` · `S○`(그 단계에서 함) · `일부러 다름`(이유가 있어 다르게 둠) · `불가능`(이유와 대안을 적음) · `해당 없음`(Windows 전용) · `선생님 결정`(코드와 README가 달라 정해야 함)

**확인 방법**: `G` 기준 그림(`Tests/golden/`, `build.sh --test`) · `A` 글 점검(단언, `--test`나 `--selftest`) · `T` 선생님이 직접 (단계별 확인 목록) · `—` 확인할 것 없음

## 맥에서만 다름 (일부러)

| 무엇이 다른가 | 맥 상태 | 확인 | 결정 |
|---|---|---|---|
| 드로잉 중에는 드로잉 키가 아닌 키(→·스페이스·리모컨·글자)를 막는다. ⌘·⌃ 조합은 그대로 | 일부러 다름 (S4, 선생님 확인 대기) | A, T | 결정 13, D2 |
| 드로잉 중 다른 앱·데스크톱으로 넘어가거나 잠자기·화면 잠금이면 Esc처럼 끈다. ⌘Tab은 막을 수 없어 "넘어가면 끔"이 대안이다 | 일부러 다름 (S4, 선생님 확인 대기) | A, T | 결정 14, D7 |
| 끄고 나서 ⌘Z로 되살리는 기간은 10분. 끄면 그림은 버리고 선 목록만 남긴다 (Windows는 30초) | S5 | A | 결정 15 = 결정 ③, D4 |
| ⌥+끌기로도 지운다, ⌘Z 실행 취소, 위젯 우클릭 메뉴(메뉴 막대 아이콘이 노치 뒤로 숨을 때) | 완료 | T | 맥 추가 |
