# Windows 판 단축키 안내에 나중에 가져갈 맥 판의 장점

> Windows 세션에서만 `focus-draw.ahk`·`shortcuts.png`·`shortcuts-guide.html`을 고친다. 맥 세션은 이 메모만 남긴다(2026-10-04, 선생님 요청).

## 맥 판에서 좋았던 것 (선생님 평가: "너무 좋다")

**키 위의 색 막대가 지금 설정 색을 그대로 따라간다.** 설정 창에서 숫자키 1~9·0·칠판 W/E/R의 색과 투명도를 바꾸고
"드로잉 모드 단축키 보기"를 다시 열면 키 위 막대가 새 색으로 바뀐다.

- Windows 판은 키보드 그림이 고정 PNG(`shortcuts.png`)라 키 위에는 기본 색이 그려져 있고, 바꾼 색은 그림 아래 띠(`AddGuideColorStrip`, `focus-draw.ahk`)로 따로 보여 준다. 그래서 사용자는 키와 띠를 눈으로 이어서 읽어야 한다.
- 맥 판은 키보드를 SwiftUI로 직접 그려서(`mac/Sources/UI/KeyboardView.swift`의 `KeyboardLayout.rows`) 각 키가 `Settings`의 색을 읽는다. 투명도를 낮춘 색은 막대도 같은 비율로 옅게 보인다. 투명 칠판(Q)은 체크무늬, 레이저 펜(A)은 지금 펜 색이 사라지는 띠, 무지개 펜(S)은 무지개 띠.
- 가져가려면: `shortcuts-guide.html`의 키 위 `.bar` 색을 고정값 대신 Windows 설정값으로 채워 PNG를 창을 열 때 만들거나(HTML→이미지가 어려우면 GDI+로 키 막대만 직접 칠하기), 최소한 아래 띠를 키 위로 옮긴다.

## Windows 판에서 가져온 것 (맥 판에 적용 완료)

- 기능 묶음별 키 테두리 색 + 맨 위 범례 띠 (색 바꾸기·칠판·도형·선 굵기·지우기·특수 펜)
- 아래 설명을 "키 → 하는 일" 두 칸 카드로 묶기, 쓰지 않는 키 안내 줄은 뺌
- 맥에만 있는 것: 실제 맥북 배열·키 폭, ⇧(사각형)·⌃(원)·⌥(지우개) 키에 그림 표시, Z/X/C에 직선·물결·화살표 그림
