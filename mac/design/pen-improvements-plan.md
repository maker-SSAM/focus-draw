# 특수 펜·단축키 개선 계획 (2026-10-05, 선생님 요청)

맥 세션에서 하고, Windows가 따라갈 것은 [windows-todo.md](windows-todo.md)에 줄을 남긴다. 한 묶음씩 세션을 나눈다.

## 묶음 A: 레이저·무지개 그리기 (지금 진행)
1. **레이저 테두리 정교하게** (2026-10-05 맥 구현·선생님 확인: 번짐·빨리 긋기·굵기 최대 개선, 줄기 시작할 때 smoothstep 적용은 선생님 재확인 대기) — 움직임(머묾 → 사라짐)은 그대로. 기준 그림은 [images/laser-before.png](images/laser-before.png)
   (`FocusDraw --laserpic <폴더>`로 앱의 그리기 코드가 직접 뽑은 그림; 화면 캡처 없이 모양을 본다).
   - 확인한 어색함: 번짐이 겹친 4개의 층(`LASER_LAYERS`)이라 층 사이 경계가 단계로 보임 / 끝점이 둥근 덩어리로 보임 /
     흰 바탕에서는 가운데 흰 심(mix 0.6)이 구멍처럼 보임.
2. **무지개 레이저** (2026-10-06 맥 구현·선생님 확인, 둘레 빛은 시작점 색으로 고정): S(무지개펜) 다음 A(레이저)면 무지개 레이저. 숫자키를 누르면 그 색의 드로잉 펜으로 돌아간다(레이저 상태에서 3번이 노랑 펜이 되는 것과 같은 규칙). 도형(직선·사각형·원 등)도 무지개 적용.
   색 변화 속도는 무지개펜과 같은 `RAINBOW_CYCLE_PX`. 이미 그은 획은 그은 때의 색 유지.
3. **무지개펜의 점(붓 동그라미)** (2026-10-06 맥 구현): 무지개펜일 때 점 자체를 무지개 그라데이션으로 칠한다(가만히, 타이머 없음).

## 묶음 B: 설정 항목
4. **레이저 옵션 3가지** (2026-10-06 맥 구현, 이름 `LaserHold`·`LaserFade`·`LaserGlow` 선생님 확정): 머무는 시간(`LASER_HOLD` 0.5초), 사라지는 시간(`LASER_FADE` 0.5초), 빛 번짐 정도. 기본값은 지금 값.
   설정 파일 이름(Windows와 같게 정한 뒤 구현): `[Draw] LaserHold`, `LaserFade`, `LaserGlow` (제안, Windows 세션과 확정).
5. **숫자키별 두께**(요청 6번): `[DrawKeys] Step1`~`Step9` 같은 항목 + 설정 창 숫자키 목록에 두께 칸. 값이 없으면(기본) 지금처럼 현재 두께를 유지해
   기존 동작을 지킨다. 숫자키를 누르면 색·불투명도에 두께도 함께 바뀐다. Windows와 항목 이름이 같아야 한다. (나중에 실시)

## 묶음 C: 키보드 그림 옵션 창 (나중에 실시)
6. **단축키 그림에서 키를 누르면 옵션 창**(요청 5번): 맥은 `KeyboardView`(SwiftUI)에서 키를 클릭하면 작은 창(색·불투명도·두께)을 띄운다.
   설정 창의 같은 값을 읽고 쓴다. 바뀌는 점: 지금은 그림을 클릭하면 닫히는데, 클릭이 옵션 창으로 쓰이므로 닫기는 Esc·창 닫기 단추로만 한다.
   Windows는 키보드 그림이 고정 PNG(`shortcuts.png`)라 키별 클릭 영역을 따로 만들어야 해서 어렵다 → 맥에서 먼저, Windows는 나중에 정한다.
   묶음 B의 5번(숫자키별 두께)이 먼저 되어 있어야 옵션 창에 두께 칸을 넣을 수 있다.
