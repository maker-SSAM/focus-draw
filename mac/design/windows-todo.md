# Windows 세션이 이어받을 목록

맥 세션은 Windows 파일(`focus-draw.ahk` 등)을 고치지 않는다. 맥에서 먼저 한 것 중 Windows도 같게 해야 할 것을 여기에 한 줄씩 쌓는다.
Windows 세션 첫마디 예: "mac/design/windows-todo.md를 읽고 ○○ 줄을 Windows 판에 맞춰 줘." 끝나면 상태를 "완료"로 고친다.
시작하기 전에 OneDrive 동기화(초록 체크)와 `git pull`을 확인한다. 두 PC에서 동시에 작업하지 않는다.

| 무지개 레이저·무지개 점·도형 무지개 | S(무지개 펜) 다음 A면 무지개 레이저, 숫자키를 누르면 그 색의 일반 펜이 되고 무지개가 풀림(그 뒤 A는 그 색 레이저). 본체는 그은 거리만큼 무지개(`RAINBOW_CYCLE_PX`), **둘레 빛은 그 획의 시작점 색 한 가지**(한 획 동안 고정, 다음 획은 이어지는 색이라 획마다 빛이 달라짐 — 선생님 결정 2026-10-06; 점마다 빛 색을 바꾸면 겹치거나 되돌아오는 곳에서 덮어쓰고 잘려 보였음), 흰 심은 흰빛. 도형도 무지개(사각형·직선·화살표는 변을 약 5pt마다 채워 색이 고르게 돎). 무지개 펜의 붓 동그라미는 무지개 원판, 무지개 레이저 커서는 가운데 무지개 원판 + 둘레 빛 = 다음 획이 시작할 색(손을 떼면 바뀜). **주의**: 줄어드는 동안 사라진 앞쪽 점을 목록에서 지우므로 빛 색을 첫 점에서 읽으면 줄어들며 빛이 번쩍이며 바뀐다 → 획을 시작한 색조를 모든 점이 들고 있게 함(`LaserPt.glow`) | 같은 규칙과 모양. 맥 코드: `Renderer.swift`(`renderRainbow`·`rainbowize`), `DrawKeyboard.swift`(S·숫자키), `DrawController.swift`(`rainbowColor`·`activeLaserRainbow`), `BrushCursor.swift`(`rainbowDotImage`·`laserCursorImage`) | — | S→A로 선 여러 개를 겹쳐 긋기, 숫자키 후 A, 도형, [images/laser-after.png](images/laser-after.png) 옆에 무지개 그림은 `FocusDraw --laserpic`의 rainbow·rainbow-strokes | 완료 (2026-10-06 Windows. 빛 색은 획이 `glow`로 따로 들고 있음. 무지개 펜 자유선도 약 4px마다 색을 돌려 빨리 그어도 계단 없음) |
| 레이저 옵션 3가지 | (2026-10-06 맥 구현) 설정 창 드로잉 탭에 "레이저 머묾"(ms, 0~3000, 간격 100)·"레이저 사라짐"(ms, 100~3000)·"레이저 빛 번짐"(%, 0~200, 간격 10). 번짐 0%는 빛 없이 본체와 흰 심만, 200%는 빛이 두 배 넓게(층 굵기 배율 1+2·(1−u)·g, 1 미만이면 진하기도 g배). 파일에 없고 기본값이면 쓰지 않음(`SettingsSchema.macFirst`) | 같은 이름으로 설정 항목·설정 창 칸 추가, ahk의 `LASER_HOLD_MS`·`LASER_FADE_MS`를 설정값으로. 다 되면 맥의 `SettingsSchema.macFirst`에서 세 키를 빼서 "표의 키가 모두 ahk에 있음" 점검이 다시 이 키들도 보게 한다 | `[Draw] LaserHold`=500, `LaserFade`=500, `LaserGlow`=100 | 값을 바꿔 저장 → 레이저 머묾·사라짐·번짐이 바뀜, 두 판이 같은 파일을 읽음 | 완료 (2026-10-06 Windows: 설정 창 드로잉 탭 "레이저 펜 (A)" 상자. **선생님 결정: 기본값이어도 늘 파일에 쓴다**(다른 설정과 같게, 2.0까지 두 판의 설정 파일을 똑같이). 맥은 `macFirst`에서 세 키를 빼면 같아진다 — 맥에서) |
