## Focus & Draw 2.0.0 — Windows · 맥 함께

수업 중 화면의 한 곳을 강조하고(F8), 화면 위에 바로 필기하는(F9) 무료 프로그램입니다. **이번 판부터 맥 판이 함께 나옵니다.**

### 내려받기
- **Windows 10 / 11** → `Focus-Draw-2.0.0.zip` — 압축을 풀고 `focus-draw.exe` 실행
- **맥 (macOS 15 이상)** → `Focus-Draw-2.0.0-mac.zip` — 압축을 풀고 앱을 "응용 프로그램" 폴더로 옮긴 뒤 실행. 처음 한 번은 **시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기"**가 필요합니다(Apple 서명이 없는 개인 제작 앱). 자세한 방법은 zip 안의 `맥용 읽어주세요.txt`

### 새로 생긴 것
- **맥 판**: Windows 판과 같은 쓰임새(강조·클릭 효과·드로잉·칠판·레이저·무지개 펜·위젯·설정 창). 단축키는 `F8`·`F9`(맥북은 fn과 함께) 또는 `control+option+1`·`2`. Windows 판과 다른 점은 [README "맥에서 쓰기"](https://github.com/maker-SSAM/focus-draw#맥에서-쓰기)
- **새 버전 확인**: 설정 창 "일반" 탭에 "현재 ○ · 최신 ○"이 보이고 **[받으러 가기]**로 내려받는 곳이 열립니다. 설정 창을 열 때만 확인하고, 켤 때·수업 중에는 인터넷에 접속하지 않습니다
- **레이저 펜(`A`) 다듬기**: 계단 없는 부드러운 빛, 빨리 그어도 곡선으로 이어짐. 설정 창 "드로잉" 탭에서 **유지 시간·사라지는 시간·빛 번짐**을 정할 수 있습니다
- **무지개 레이저**: `S`(무지개 펜) 다음 `A`
- **숫자키별 굵기**: 숫자키 `1`~`9`마다 색·투명도와 함께 굵기도 정해 둘 수 있습니다
- **휠 진하기**: 휠을 100%까지 올리면 정말 불투명해집니다(설정 창의 투명도는 처음 잡히는 진하기)
- **빠르게 그은 자유선**이 더 매끄럽게 이어집니다
- **단축키 그림**의 키 위 색 막대가 지금 설정한 색을 따라갑니다
- 설정 창의 제작자 이름을 누르면 제작자 페이지가 열립니다

### 고친 것
- `settings.ini`를 손으로 고쳐 숫자 자리에 글자·빈 값·`#FF0000` 같은 값이 들어가도 시작할 때 오류가 나지 않고 기본값으로 시작합니다

### 1.0을 쓰고 계셨다면
- 새 폴더에 풀어 쓰셔도 되고, 예전 폴더의 `focus-draw.exe`만 바꿔 넣으면 `settings.ini`(색·크기·단축키)가 그대로 이어집니다
- 1.0에는 새 버전 확인 기능이 없어서 이 소식은 따로 알려 드립니다. 2.0부터는 설정 창에서 확인하실 수 있습니다
