Focus & Draw (포커스 앤 드로우)
수업용 화면 강조 · 판서 도구
마우스 주위를 밝게 강조하고, 화면 위에 바로 판서할 수 있습니다.
제작: maker_SSAM · 무료 (MIT 라이선스)
지원 환경: Windows 10 / 11
최신 버전 내려받기: https://github.com/maker-SSAM/focus-draw/releases/latest
소스 · 사용법: https://github.com/maker-SSAM/focus-draw


[ 0. 이런 프로그램입니다 ]

수업에서 많이 쓰는 두 프로그램 - 판서하는 ZoomIt, 마우스를 강조하는
SpotMouse - 의 핵심 기능을 하나로 합쳤습니다.

- 설치가 없습니다. exe 하나로 바로 실행됩니다.
- 화면 구석의 작은 위젯이나 단축키로 필요할 때 바로 켜고 끕니다.
- 가볍습니다. 켜 두기만 했을 때 CPU 0%, 메모리 약 14MB
  (ZoomIt 약 12MB, SpotMouse 약 96MB와 같은 조건에서 잰 값)
- 색 · 굵기 · 투명도 · 단축키 등 대부분을 내 수업에 맞게 바꿀 수 있습니다.
- 전자칠판에서도 편하게 쓰도록 만들었습니다 (아래 3번 참고).
  칠판이 아니라 PC에서 동작하므로, 칠판 제조사와 관계없이
  어느 교실에서나 같은 방법으로 판서할 수 있습니다.


[ 1. 먼저 압축을 풀어주세요 ]

압축을 푼 뒤, 그 안의 focus-draw.exe 를 실행해주세요.
바탕화면이나 문서처럼 평범한 폴더에 두면 됩니다.

  ** 압축 안에서 바로 실행하거나 Program Files에 두면 **
  ** 설정이 저장되지 않습니다 **


[ 2. 파란 경고창이 뜨면 ]

"Windows의 PC 보호"라는 파란 창이 뜰 수 있습니다.
개인이 만든 프로그램이라 전자서명이 없어서 나오는 안내입니다.

  추가 정보  ->  실행

을 누르시면 됩니다. 같은 PC에서는 한 번만 확인하면 됩니다.
백신 프로그램이 잘못 막는 경우도 같은 이유입니다.


[ 3. 쓰는 법 ]

실행하면 화면 오른쪽 아래에 작은 위젯이 나타납니다.

  강조 버튼   마우스 주위에 동그란 강조 표시를 켜고 끕니다
  판서 버튼   화면 위에 그림을 그릴 수 있습니다
  톱니바퀴    설정 창 (색, 굵기, 단축키 등)
  X 버튼      위젯만 숨깁니다 (프로그램은 계속 켜져 있습니다)

단축키
  F8    강조 켜기/끄기
  F9    판서 켜기/끄기          (설정 창에서 바꿀 수 있습니다)

  F8 · F9는 앞에 있는 프로그램에도 그대로 전달됩니다.
  예) 한글에서 F8 -> 맞춤법 검사와 강조 켜기가 함께 일어납니다.

판서 중에만 쓰는 키 - 키 하나만 누르면 됩니다
  드래그              자유롭게 그리기
  Shift + 드래그      사각형        Ctrl + 드래그   원
  Z / X / C + 드래그  직선 / 물결 / 화살표
                      (Shift를 함께 누르면 0도·45도·90도로 반듯하게)
  A                   사라지는 펜 (레이저 포인터처럼 빛나다 저절로 사라짐)
  S                   무지개 펜 (긋는 동안 색이 저절로 바뀜)
                      (한 번 누르면 계속 유지, 숫자키를 누르면 보통 펜으로.
                       도형에도 적용됩니다 - 사라지는 사각형, 무지개 화살표 등)
  오른쪽 버튼 드래그  지우개
  1 ~ 9               색 바꾸기 (빨주노초파남보 + 검정 + 흰색)
  0                   설정 창의 기본 색으로 돌아오기
  마우스 휠           색 진하게 / 연하게
  Q / W / E / R       칠판 (투명 / 흰색 / 초록 / 검정)
  + / -               선 굵기   (오른쪽 버튼과 함께 누르면 지우개 크기)
  Ctrl + Z            방금 그은 것 취소
  Delete              전부 지우기
  Esc                 지우고 판서 끄기

  키는 영어 첫 글자가 아니라 키보드 자리로 모아 두었습니다.
  숫자 줄 = 펜 색, Q 줄 = 칠판, A 줄 = 특수 펜, Z 줄 = 선 도형.

  외우지 않아도 됩니다. 설정 창 "단축키" 탭의
  "드로잉 모드 단축키 보기" 버튼을 누르면 키보드 그림으로 볼 수 있습니다.

전자칠판에서 (터치)
  손가락 · 터치펜      글씨 쓰기 (닿는 순간부터 바로 그려집니다)
  손날로 문지르기      지우개
  두 손가락으로 톡     방금 그은 것 취소
  펜 뒤쪽              지우개 (앞뒤를 구분하는 펜일 때)

  칠판 앞에 서서도 키보드까지 가지 않고 대부분의 일을 할 수 있습니다.

  전자칠판은 대부분 PC 화면을 미러링해서 씁니다. 화면 위에 필기하는
  기능은 칠판 제조사마다 달라서, 교실을 옮기면 사용법을 몰라 당황하기
  쉽습니다. 이 프로그램은 PC에서 동작하므로 칠판의 기능과 관계없이
  미러링된 화면 위에 늘 같은 방법으로 판서할 수 있습니다.


[ 4. 내 수업에 맞게 바꾸기 ]

설정 창(톱니바퀴)의 탭별로 바꿀 수 있는 것들입니다.

  일반      Windows 시작 시 자동 실행, 모든 설정값 초기화
  포커스    강조의 색 · 크기 · 투명도, 강조 중 커서 숨기기,
            클릭할 때 퍼지는 링 효과 (왼쪽 · 오른쪽 따로)
  드로잉    기본 펜의 색 · 굵기 · 투명도, 지우개 크기
            숫자키 1~9 펜마다 색과 투명도 (투명도를 낮추면 형광펜)
            칠판 W / E / R 의 색과 투명도
  위젯      위젯의 크기 · 투명도 · 배경색
            위젯 끄기 / 작업표시줄 아이콘 켜기 · 끄기
            (둘 다 끄고 단축키로만 쓸 수도 있습니다)
  단축키    F8 · F9 대신 쓸 키, 드로잉 모드 단축키 그림 보기


[ 5. 설정은 "저장"을 눌러야 유지됩니다 ]

설정 창에서 값을 바꾸면 화면에 바로 반영되지만,
아래쪽 "저장" 버튼을 눌러야 다음에 열 때도 유지됩니다.

저장하면 이 폴더 안에 settings.ini 라는 파일이 생깁니다.
여기에 내 설정이 들어 있습니다.

  ** 이 폴더째 USB나 클라우드 드라이브에 옮기면 **
  ** 다른 PC에서도 내 설정 그대로 쓸 수 있습니다 **

(exe 파일만 옮기면 설정은 따라가지 않고 처음 값으로 돌아갑니다)


[ 6. 알아두시면 좋은 것 ]

- 판서를 켜면 화면 전체가 덮여서, 그리기 외에는 클릭이 되지 않습니다.
  끄려면 위젯의 판서 버튼이나 F9, 또는 Esc 를 누르세요.

- 끄는 방법에 따라 그린 것이 남기도 하고 지워지기도 합니다.
    F9                  그린 것과 칠판이 그대로 남습니다
                        (다른 화면을 잠깐 보여주고 돌아와 이어 쓸 때)
    Esc / 위젯 버튼     그린 것과 칠판을 지우고 끕니다
  실수로 지웠다면 30초 안에 판서를 다시 켜고 Ctrl + Z 를 누르세요.

- 판서 중 Win+Shift+S 로 화면을 캡처할 수 있습니다.
  캡처 도구가 떠 있는 동안에는 마우스 커서가 평소 모양으로 돌아옵니다.

- 프로그램을 작업 관리자로 강제 종료하면 마우스 커서가 안 보일 수 있습니다.
  그럴 땐 프로그램을 다시 실행하면 원래대로 돌아옵니다.
  (트레이 아이콘 우클릭 -> 종료 로 끄시면 이런 일이 없습니다)


[ 7. 문제가 있거나 건의할 점이 있으면 ]

설정 창의 "일반" 탭에 적힌 버전 번호와 함께 알려주시면
훨씬 도움이 됩니다.
