Focus & Draw (포커스 앤 드로우)
수업 중 화면 위에 판서하고, 마우스 위치를 강조해주는 가벼운 도구입니다.
제작: maker_SSAM · 무료 (MIT 라이선스)


[ 1. 먼저 압축을 풀어주세요 ]

압축 파일 안에서 focus-draw.exe를 바로 실행하면 안 됩니다.
그러면 임시 폴더에서 돌아가기 때문에, 설정을 바꿔 저장해도 다음에
열면 사라집니다.

압축을 풀어 폴더째 바탕화면이나 문서 폴더에 두신 뒤,
그 안의 focus-draw.exe 를 실행해주세요.


[ 2. 파란 경고창이 뜨면 ]

"Windows의 PC 보호"라는 파란 창이 뜰 수 있습니다.
서명되지 않은 개인 제작 프로그램에는 항상 뜨는 안내입니다.

  추가 정보  ->  실행

을 누르시면 됩니다. 같은 PC에서는 한 번만 확인하면 됩니다.


[ 3. 쓰는 법 ]

실행하면 화면 오른쪽 아래에 작은 위젯이 나타납니다.

  강조 버튼   마우스 주위에 동그란 강조 표시를 켜고 끕니다
  판서 버튼   화면 위에 그림을 그릴 수 있습니다
  톱니바퀴    설정 창 (색, 굵기, 단축키 등)
  X 버튼      위젯만 숨깁니다 (프로그램은 계속 켜져 있습니다)

단축키
  F8    강조 켜기/끄기
  F9    판서 켜기/끄기          (설정 창에서 바꿀 수 있습니다)

판서 중에만 쓰는 키
  드래그              자유롭게 그리기
  Shift + 드래그      사각형        Ctrl + 드래그   원
  Z / X / C + 드래그  직선 / 물결 / 화살표
                      (Shift를 함께 누르면 0도·45도·90도로 반듯하게)
  A + 드래그          사라지는 펜 (레이저 포인터처럼 빛나다 저절로 사라짐)
  S + 드래그          무지개 펜 (긋는 동안 색이 저절로 바뀜)
  오른쪽 버튼 드래그  지우개
  1 ~ 9               색 바꾸기 (빨주노초파남보 + 검정 + 흰색)
  0                   설정 창의 기본 색으로 돌아오기
  마우스 휠           색 진하게 / 연하게
  Q / W / E / R       칠판 (투명 / 흰색 / 초록 / 검정)
  + / -               선 굵기   (오른쪽 버튼과 함께 누르면 지우개 크기)
  Ctrl + Z            방금 그은 것 취소
  Delete              전부 지우기
  Esc                 지우고 판서 끄기

  외우지 않아도 됩니다. 설정 창 "단축키" 탭의
  "드로잉 모드 단축키 보기" 버튼을 누르면 키보드 그림으로 볼 수 있습니다.
  숫자키 색과 칠판 색은 설정 창 "드로잉" 탭에서 바꿀 수 있습니다.

전자칠판에서 (터치)
  손가락 · 터치펜      글씨 쓰기
  손날로 문지르기      지우개
  두 손가락으로 톡     방금 그은 것 취소


[ 4. 설정은 "저장"을 눌러야 유지됩니다 ]

설정 창에서 값을 바꾸면 화면에 바로 반영되지만,
아래쪽 "저장" 버튼을 눌러야 다음에 열 때도 유지됩니다.

저장하면 이 폴더 안에 settings.ini 라는 파일이 생깁니다.
여기에 내 설정이 들어 있습니다.

  ** 이 폴더째 USB나 클라우드 드라이브에 옮기면 **
  ** 다른 PC에서도 내 설정 그대로 쓸 수 있습니다 **

(exe 파일만 옮기면 설정은 따라가지 않고 처음 값으로 돌아갑니다)


[ 5. 알아두시면 좋은 것 ]

- 판서를 켜면 화면 전체가 덮여서, 그리기 외에는 클릭이 되지 않습니다.
  끄려면 위젯의 판서 버튼이나 F9, 또는 Esc 를 누르세요.

- 판서 중 Win+Shift+S 로 화면을 캡처할 수 있습니다.
  캡처 도구가 떠 있는 동안에는 마우스 커서가 평소 모양으로 돌아옵니다.

- 프로그램을 작업 관리자로 강제 종료하면 마우스 커서가 안 보일 수 있습니다.
  그럴 땐 프로그램을 다시 실행하면 원래대로 돌아옵니다.
  (트레이 아이콘 우클릭 -> 종료 로 끄시면 이런 일이 없습니다)


[ 6. 문제가 있거나 건의할 점이 있으면 ]

설정 창의 "일반" 탭에 적힌 버전 번호와 함께 알려주시면
훨씬 도움이 됩니다.
